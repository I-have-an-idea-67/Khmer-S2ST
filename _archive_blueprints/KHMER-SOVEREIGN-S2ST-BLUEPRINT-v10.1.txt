### 3.1 Specialist B: `crates/khmer-linguistics-rs` & `backend/linguistics/`

#### 1. `crates/khmer-linguistics-rs/src/normalizer.rs` & `decomposer.rs`
* **Crate Configuration (`crates/khmer-linguistics-rs/Cargo.toml`):** Must declare `[lib] crate-type = ["cdylib", "rlib"]` and `[features] extension-module = ["pyo3/extension-module"]` so both `cargo test -p khmer-linguistics-rs` and Python `maturin` builds succeed.
* **Canonical Cluster Reordering:** Normalize input to NFC, strip zero-width chars (`\u{200B}`, `\u{200C}`, `\u{200D}`, `\u{FEFF}`), and reorder any misplaced register shifter (`\u{17C9}`, `\u{17CA}`) or dependent vowel (`\u{17B6}`..`\u{17C5}`) that precedes subscript `Coeng` sequences (`\u{17D2}[\u{1780}-\u{17A2}]`) into: **Base Consonant $\rightarrow$ Subscript Coeng(s) $\rightarrow$ Register Shifter $\rightarrow$ Dependent Vowel $\rightarrow$ Diacritics / Coda**.
* **Phonological Syllable Lexicon Priority (`PHONOLOGICAL_SYLLABLE_LEXICON`):**
  Scan contiguous Khmer spans using longest-prefix matching before statistical/rule splitting:
  * `"គណនា"` $\rightarrow$ `[("គ", 1, 2), ("ណ", 1, 1), ("នា", 2, 2)]`
  * `"សុភមង្គល"` $\rightarrow$ `[("សុ", 1, 1), ("ភ", 1, 2), ("មង", 2, 2), ("គល", 2, 2)]`
  * `"ធម្មជាតិ"` $\rightarrow$ `[("ធម", 2, 2), ("ម", 1, 2), ("ជាតិ", 2, 2)]`
  * `"សង្គ្រាម"` $\rightarrow$ `[("សង", 2, 1), ("គ្រាម", 2, 2)]`
  * `"កញ្ជ្រោង"` $\rightarrow$ `[("កញ", 2, 1), ("ជ្រោង", 2, 2)]`
  * `"ប្រទេស"` $\rightarrow$ `[("ប្រ", 1, 1), ("ទេស", 2, 2)]`
  * `"កម្ពុជា"` $\rightarrow$ `[("កម", 2, 1), ("ពុ", 1, 2), ("ជា", 2, 2)]`
  * `"បញ្ហា"` $\rightarrow$ `[("បញ", 2, 1), ("ហា", 2, 1)]`
  * `"កន្លែង"` $\rightarrow$ `[("កន", 2, 1), ("លែង", 2, 1)]`
* **General 3-Rule Orthographic Resyllabification & Positional Coda Law (Verified on `"ប្រជា"`, `"ក្រសួង"`, `"កក្រើក"`, `"ស្ត្រី"`):**
  * **Step A (`"ស្ត្រី"` Rule):** Word-initial 3-consonant cluster `C1 + \u17D2 + C2 + \u17D2 + C3` with no preceding vowel stays a single syllable (`surface="ស្ត្រី"`, `coeng_id > 0`, `medial_id = 1`, `register_id = 1`, `sesqui_id = 2`).
  * **Step B (Medial Double-Coeng Split):** Split between `coda` and `c2\u17D2c3`.
  * **Step C (Medial Single-Coeng Disambiguation):**
    * **Case 2a (`"កក្រើក"` $\rightarrow$ `["ក", "ក្រើក"]`):** When `C1` has no dependent vowel, `C2 in {'ក','គ','ច','ជ','ត','ទ','ប','ព','ស'}`, and `C3 in {'រ','ល','វ','យ'}`, split *before* `C2` so `C1` is an open minor presyllable (`sesqui_id = 1`, `coda_id = 0`) and `C2\u17D2C3` starts the major syllable (`medial_id = 1`).
    * **Case 2b (Nasal/Final Coda Split & Assimilation):** When `C2 in {'ង','ញ','ន','ម','យ','រ','ល','វ'}` or `C3 not in {'រ','ល','វ','យ'}`, `C2` closes the first syllable (`sesqui_id = 2`, `coda_id > 0`). If `C1` is A-series (`register_id == 1`), `C2 in {'ង','ញ','ន','ម'}`, and `C3 in {'ង','ញ','ម','យ','រ','ល','វ'}`, lock `forced_register = 1` on the `C3` syllable.
  * **Step D (Negative-Lookahead Coda Guard for `"ប្រជា"`, `"ក្រសួង"`):** Never attach a trailing consonant as a coda if it is followed by `[\u17B6-\u17CA\u17D2]`.
  * **Positional Coda Extraction Law:** `chunk[0]` is always the onset consonant (`onset_id`). Any consonant `c` in `[\u1780-\u17A2]` at index `i > 0` where `chunk[i - 1] == '\u17D2'` is a subscript (`coeng` or `medial`). Any consonant `c` in `[\u1780-\u17A2]` at index `i > 0` where `chunk[i - 1] != '\u17D2'` is **unconditionally a coda consonant (`coda_id > 0`)**, even when no dependent vowel sign is present.
  * **Named Phonological Constants (compile-time; single source of truth shared by the Rust crate and the Python bridge):**
    * `A_SERIES` (`register_id = 1`): `['ក', 'ខ', 'ឆ', 'ដ', 'ឋ', 'ណ', 'ត', 'ថ', 'ប', 'ផ', 'ស', 'ហ', 'ឡ', 'អ']`
    * `O_SERIES` (`register_id = 2`): `['គ', 'ឃ', 'ង', 'ច', 'ជ', 'ឈ', 'ញ', 'ឌ', 'ឍ', 'ន', 'ទ', 'ធ', 'ព', 'ភ', 'ម', 'យ', 'រ', 'ល', 'វ']`
    * `MEDIAL_MAP = {'រ': 1, 'វ': 2, 'យ': 3, 'r': 1, 'w': 2, 'y': 3}`.
    * `SONORANTS = {'ង', 'ញ', 'ម', 'យ', 'រ', 'ល', 'វ'}`.
    * **Bounded Khmer Vowel & Coda Vocabularies (Prevents `nn.Embedding` Index Overflow):**
      * `KHMER_VOWELS` (`vowel_id` in `[0..27]`): `['', 'ា', 'ិ', 'ី', 'ឹ', 'ឺ', 'ុ', 'ូ', 'ួ', 'ើ', 'ឿ', 'ៀ', 'េ', 'ែ', 'ៃ', 'ោ', 'ៅ', 'ុំ', 'ំ', 'ាំ', 'ះ', 'ុះ', 'េះ', 'ោះ']` — this is a **24-entry table**, so valid `vowel_id` is in `[0..23]`; ids `[24..27]` are reserved and unassigned, guaranteeing foreign brand vowels `[28..47]` stay disjoint (matched longest-first; unseen vowel sequences default to `1`).
      * `KHMER_CODAS` (`coda_id` in `[0..17]`): `['', 'ក', 'គ', 'ង', 'ច', 'ញ', 'ត', 'ន', 'ប', 'ម', 'យ', 'រ', 'ល', 'វ', 'ស', '់']` — this is a **16-entry table**, so table hits are in `[0..15]`; any other Khmer coda consonant maps to `1 + (onset_id % 16)`, so Khmer `coda_id` is strictly in `[1..16]`; id `17` is reserved and unassigned, and none of this ever overflows `31` or collides with foreign brand codas `[18..31]`.
    * **Subscript Register Inheritance Law:** The primary subscript `C1` overrides the base consonant's register **if and only if** `C1` is a non-sonorant (`C1 not in SONORANTS`). Sonorant/liquid subscripts (`្រ`, `្ល`, `្វ`, `្ម`, `្ញ`, `្ង`, `្យ`) inherit the base consonant's register (so `"ប្រ"` and `"ក្រ"` retain `register_id = 1`).
    * **Medial Glide Extraction Law:** If a chunk has **1** subscript `\u17D2C`: if `C in MEDIAL_MAP`, set `medial_id = MEDIAL_MAP[C]` and `coeng_id = 0`; else set `coeng_id = onset_to_id[C]` and `medial_id = 0`. If a chunk has **2** stacked subscripts `\u17D2C1\u17D2C2` (e.g., `"ស្ត្រី"`): set `coeng_id = onset_to_id[C1]` and `medial_id = MEDIAL_MAP.get(C2, 1)`.
    * **Register Shifter Law:** `\u17C9` (`៉` Muusikatoan) forces `register_id = 1`; `\u17CA` (`៊` Triisap) forces `register_id = 2`.
  * **Foreign Brand CRC32 Triple Encoding (`register_id = 3`) & Reversible Surface Cache Law (`decode_batch_to_text`):**
    ```rust
    let h = crc32fast::hash(lower_word.as_bytes()) % (28 * 20 * 14);
    let onset_id = 36 + (h % 28) as i64;
    let vowel_id = 28 + ((h / 28) % 20) as i64;
    let coda_id = 18 + ((h / 560) % 14) as i64;
    ```
    * Because CRC32 modulo hashing is one-way, `BilingualCodeSwitchDecomposer` (and the Rust decomposer struct) must cache `(onset_id, vowel_id, coda_id) -> lower_word` in `self._reverse_brand_cache` whenever a foreign word (`register_id == 3`) is decomposed, and cache `(onset_id, coeng_id, medial_id, register_id, vowel_id, coda_id, sesqui_id) -> surface` in `self._reverse_khmer_cache` whenever a Khmer syllable is decomposed.
    * `decode_batch_to_text(batch: SyllableTensorBatch) -> Tuple[List[str], List[str]]` looks up each token in these caches (falling back to static inverse tables for uncached model-predicted IDs), reconstructs the per-batch text strings, collects all decoded tokens where `register_id == 3` into `codeswitch_words`, and returns `(reconstructed_texts, codeswitch_words)`.

```rust
#[no_mangle]
pub extern "C" fn hz_to_erb_rate(hz: f32) -> f32 {
    21.4 * (1.0 + 0.00437 * hz).log10()
}

pub fn apply_mid_side_spectral_erb_mask(
    mid_real: &mut [f32],
    mid_imag: &mut [f32],
    _side_real: &[f32],
    _side_imag: &[f32],
    erb_mask_64: &[f32],
    sample_rate: f32,
    n_fft: usize,
) {
    let min_erb = hz_to_erb_rate(120.0);
    let max_erb = hz_to_erb_rate(8000.0);
    let num_bins = mid_real.len().min(mid_imag.len());

    for k in 0..num_bins {
        let freq_hz = (k as f32) * (sample_rate / (n_fft as f32));
        if freq_hz < 120.0 || freq_hz > 8000.0 {
            continue; // Preserve <120Hz sub-bass and >8kHz air at unity gain 1.0
        }
        let erb_val = hz_to_erb_rate(freq_hz);
        let norm = (erb_val - min_erb) / (max_erb - min_erb);
        let erb_idx = ((63.0 * norm).floor() as isize).clamp(0, 63) as usize;
        let gain = erb_mask_64[erb_idx].clamp(0.0, 1.0);
        mid_real[k] *= gain;
        mid_imag[k] *= gain;
        // Side channel is NEVER modified (100% stereo width preservation)
    }
}
```

### 3.4 Specialist A: Prose-Locked Cartridge Integration Laws (`backend/nn_cartridges/`)

The laws below are mandatory implementations fixed by prose rather than by the parameter ledger. **Where an internal width or parameter count appears in both Part 3.3 and this section, Part 3.3 is authoritative** (it is the `239.97M` ledger); the laws here fix structure, conditioning, kernel geometry and mathematics only.

1. **FiLM-Conditioned 3-Stem Separation & `filter_dominant_speakers` (`stem_and_mode_gate.py`):**
   * Compute complex STFT (`n_fft=512`, `hop=160`, Hann window). Project magnitude bins (`257`) to `config.separator_d_model`.
   * When `primary_spk_emb` `(B, 512)` is provided, modulate hidden states prior to the causal GRU via Feature-wise Linear Modulation:
     `h_mod = h * (1.0 + tanh(gamma(primary_spk_emb))) + beta(primary_spk_emb)`
   * `filter_dominant_speakers(stem_a, stem_b, min_db_ratio=DOMINANCE_MIN_DB_RATIO, force_dual_speakers=False)`:
     `db_diff = 20.0 * log10(RMS(stem_b) / RMS(stem_a))`
     Return stacked `(2, T)` tensor if `force_dual_speakers` is `True` or if `db_diff >= min_db_ratio` and `RMS(stem_b) > SILENCE_RMS_THRESHOLD`; otherwise return `stem_a` of shape `(1, T)`.

2. **`StreamingEarCartridge` (`ear_cartridge.py`):**
   * **Input:** `wav_16k` `(B_spk, T_wav)` and `source_lang: LanguageCode = "en"`.
   * **Frontend:** Log-Mel spectrogram (`n_fft=512`, `hop=160`, `n_mels=N_MELS`) followed by a 4x strided causal 1D convolutional subsampler (25 Hz token rate, 40 ms frame step) projecting to `config.ear_d_model` and adding a 4-language `source_lang` embedding (`nn.Embedding(4, config.ear_d_model)`).
   * **Backbone:** `config.ear_layers` causal FastConformer blocks (Multi-Head Self-Attention + Depthwise Separable Convolution `kernel_size=31` + single FFN) followed by an output projection to `SEMANTIC_DIM = 512` -> `semantic_bus` `(B_spk, T_sem, 512)`.
   * **Instantaneous Speech Rate Estimator (`r_sps`):** A 1D energy-envelope peak-rate head over `semantic_bus` predicting syllables per second `r_sps in [1.5, 9.0]` of shape `(B_spk,)`.

3. **Timbre & Prosody Disentanglement (`DisentangledEmotionEncoder`, `universal_core.py`):**
   1. Apply `nn.InstanceNorm1d(N_MELS, affine=False)` across the time axis of the reference Mel spectrogram to strip channel/mic gain.
   2. Apply a causal low-pass moving-average filter (`kernel_size=25` frames at 100 Hz, ~4 Hz cutoff) to isolate macro pitch/energy prosody contours from fast phonetic articulations.
   3. Cross-attend `EMOTION_NUM_TOKENS = 32` learnable query tokens over the filtered prosody features through `config.emotion_layers` Perceiver blocks and project to `(B_spk, 32, 512)` -> `emotion_tokens`.
   4. Pass the mean-pooled emotion representation through `GradientReversalFn.apply(pooled, alpha)` into a 4-way language classifier head (`"en"`, `"km"`, `"th"`, `"vi"`) returning `(emotion_tokens, lang_logits)`.

4. **Exact ISTFT Waveform Reconstruction (`VocosISTFTHead`):**
   * Takes synthesized Mel spectrogram `(B_spk, N_MELS, T_target)`, processes through `config.vocos_layers` ConvNeXt residual blocks (depthwise convolution `dwconv k=7` + FFN `d_model -> vocos_intermediate_dim // 2 -> d_model`) at 24 kHz frame rate, projects to `n_fft + 2 = 1026` channels (`n_fft=1024`, `hop=HOP_LENGTH=256`, `n_bins=513`) representing log-magnitude `M` and phase `(cos_phi, sin_phi)`, and reconstructs the dry 24 kHz time-domain waveform via `torch.istft` with `length = T_target * HOP_LENGTH`.

5. **`KhmerMouthCartridge` & Rate-Conditioned Semantic-to-Syllable Bridge (`mouth_cartridge.py`):**
   * **Step 1: Rate-Conditioned Contraction ("Inner Monologue" Bridge when `explicit_syll_batch is None`):**
     * `gamma_contract = 0.78` if `r_sps > 5.5` (fast-talker colloquial contraction), else `1.00`.
     * `L_syll = max(1, round(T_orig * min(r_sps, 6.5) * gamma_contract))`.
     * Interpolate `fused_semantic_bus` `(B_spk, T_sem, SEMANTIC_DIM)` (conditioned on a 4-language `target_lang` embedding `nn.Embedding(4, SEMANTIC_DIM)`) to length `L_syll` and project through 7 parallel linear classification heads to predict logits for `onset` (`64`), `coeng` (`64`), `medial` (`4`), `register` (`4`), `vowel` (`48`), `coda` (`32`), and `sesqui` (`3`).
     * **Bidirectional Target Language Invariant:** If `target_lang == "en"`, clamp predicted `register_ids = 3` (Modal) and `sesqui_ids = 2` (Major). If `target_lang == "km"`, restrict `register_ids` to `{1, 2}` where `g_t < 0.5` and set `register_ids = 3` where `g_t >= 0.5` (brand passthrough).
   * **Step 2: 7-Slot Compositional Embedding:** Sum the 7 embedding lookup tables (`onset_emb + coeng_emb + medial_emb + register_emb + vowel_emb + coda_emb + sesqui_emb`, each of dimension `SEMANTIC_DIM`) with the length-interpolated `fused_semantic_bus` to form `syll_hidden` `(B_spk, L_syll, SEMANTIC_DIM)`.
   * **Step 3: Duration Alignment & Euler OT-CFM Synthesis:**
     * Pass `syll_hidden` and `sesqui_ids` through `LearnedDurationAligner` to upsample to `target_frames` `(B_spk, T_target, SEMANTIC_DIM)`.
     * Condition the `config.mouth_layers` Diffusion Transformer (`DiT`) blocks on upsampled hidden states (via frame-aligned addition + timestep AdaLN-Zero modulation) and `emotion_tokens` (via Cross-Attention in every DiT block).
     * During inference (`forward_s2st`), integrate from Gaussian noise `x_0 ~ N(0, I)` of shape `(B_spk, N_MELS, T_target)` from `t = 0.0` to `t = 1.0` in `N_steps = config.euler_steps` uniform Euler steps (`dt = 1.0 / N_steps`):
       `x_{k+1} = x_k + dt * v_theta(x_k, t_k, cond, emotion_tokens)`.

6. **Playback-Scaled & Minor-Clamped `LearnedDurationAligner` (`duration_aligner.py`):**
   * **Target Frame Computation (`compute_elastic_target_frames`):**
     * If `speech_rate_sps > 4.8` and `trailing_pause_ms > 40.0`, add `borrow_ms = min(MAX_ELASTIC_PAUSE_BORROW_MS, 0.65 * trailing_pause_ms)` to `orig_duration_sec`: `effective_sec = orig_duration_sec + (borrow_ms / 1000.0)`. Otherwise `effective_sec = orig_duration_sec`.
     * Divide by clamped playback rate: `scaled_sec = effective_sec / clamp(playback_rate, 0.5, 2.5)`.
     * `target_frames = max(6, round(scaled_sec * SAMPLE_RATE_OUT / HOP_LENGTH))`.
   * **Post-Normalization Hard Minor Ceiling (`forward`):** Apply sesquisyllabic prior (`0.25` for `sesqui_id == 1`, `1.00` for `sesqui_id == 2`) to predicted positive durations `raw_dur`, normalize so `sum(norm_dur) == target_frames`, and then hard-clamp minor syllables:
     * `clamped_minor = clamp(norm_dur, max=MINOR_SYLLABLE_MAX_FRAMES)` for all tokens where `sesqui_id == 1`.
     * Sum all excess frames `excess_frames = sum(norm_dur - clamped_minor)` over minor syllables and redistribute `excess_frames` proportionally across major syllables (`sesqui_id == 2`) so total duration still sums to `target_frames` while every minor presyllable is guaranteed `<= MINOR_SYLLABLE_MAX_FRAMES` frames (~64 ms). Upsample syllable hidden states to `target_frames` using Gaussian soft-attention (`sigma = 1.5`).

7. **Gradient Reversal & Code-Switch Pointer (`universal_core.py` & `codeswitch_router.py`):**
   * `GradientReversalFn`: Custom `torch.autograd.Function` whose forward pass is the identity `f(x) = x` and backward pass multiplies incoming gradients by `-alpha` (`grad_input = -alpha * grad_output`).
   * `AcousticPointerCodeSwitchBridge`: Predicts frame/token gate `g_t in [0, 1]` (or overrides `g_t = torch.full_like(g_t, force_gate)` when `force_gate is not None` for deterministic unit testing) and outputs `((1.0 - g_t) * H_target + g_t * CrossAttn(Q=H_target, K=H_source_acoustic, V=H_source_acoustic), g_t)`.

8. **`SceneAcousticMatcher` Velvet-Noise Construction & Loudness Lock (`stem_and_mode_gate.py`):**
   * Construct the 6,000-tap sparse Velvet-Noise buffer (`pulse_indices = 24, 48, ..., 5976` with random `+/- 1.0` signs) explicitly on `device="cpu"` using a local `torch.Generator(device="cpu").manual_seed(42)` before `register_buffer`. This guarantees global `torch.get_rng_state()` is **never** mutated AND instantiating inside `with torch.device("meta"):` never throws a CPU-generator/meta-device mismatch `RuntimeError`.
   * **Sinc-Free & Autograd-Safe 96-Tap 24kHz Mic EQ:** Linearly interpolate `mic_eq_residual_16k` `(B_spk, 1, MIC_EQ_TAPS_16K)` to `MIC_EQ_TAPS_24K` taps at 24 kHz. Anchor tap `0` to `1.0` **100% out-of-place** (never use in-place slice assignment `[:, 0, 0] = 1.0`) by slicing taps `1..95` (`eq_tail = F.pad(eq_res_24k[:, :, 1:], (1, 0))`), adding a unit impulse vector `[1, 0, ..., 0]` created via `F.pad(torch.ones_like(eq_tail[:, :, :1]), (0, 95))`, and normalizing to unit L2 norm.
   * **Autograd-Safe 6,000-Tap Velvet-Noise RIR:** Compute exponential decay envelope `E(t) = exp((-6.9078 / clamp(rt60_sec, min=0.05)) * t_sec)` for `t_sec in [0, 0.25]s`, multiply by `velvet_grid.to(eq_wav.device)`, normalize tail to unit L2 norm, scale by `wet_gain`, and add an out-of-place unit impulse vector `[1, 0, ..., 0]` at tap `0`.
   * **Loudness Lock:** Scale output by `clamp(target_rms_scalar / current_rms, 0.2, 4.0)` and clamp waveform to `[-0.98, 0.98]`.

9. **Prose-Locked Value Bounds & Activation Functions:**
   * **Activation (`GELU`):** `GELU` is the mandatory activation for every feed-forward path — `Causal3StemSeparator` bottleneck MLP, `VocalModeGate` `Conv1d` + `GroupNorm` stacks, the FastConformer ConvModule and FFN in `StreamingEarCartridge`, `DisentangledEmotionEncoder` Perceiver blocks, `AcousticPointerCodeSwitchBridge` cross-attention blocks, and `KhmerMouthCartridge` DiT blocks. The separator's recurrent path uses `nn.GRU` (no activation substitution) and `VocosISTFTHead` ConvNeXt blocks use `GELU`.
   * **Bounded `SeparatedSceneSlice` Outputs** — `Causal3StemSeparator` heads must clamp at emission time:

| :--- | :--- | :--- |

### 3.5 Specialist C: Guarded 0-Hz VTLP, Text-Free Infilling & Dual-Profile Training Law (`backend/training/`)

1. **`warp_formants_vtlp(mel, alpha_min=0.85, alpha_max=1.15, pivot: float = 0.65)` (`augmentations.py`):**
   * Let normalized frequency coordinate `u in [0.0, 1.0]` span the `M` Mel bins where `u = 0.0` is bin `0` (0 Hz floor) and `u = 1.0` is bin `M - 1` (Nyquist).
   * Sample warp factor `alpha ~ Uniform(alpha_min, alpha_max)` per batch item and compute the guarded piecewise boundary:
     `boundary = clamp(alpha * pivot, min=0.10, max=0.92)`
   * Compute warped normalized frequency `u_warped in [0.0, 1.0]`:
     * For `u <= boundary`: `u_warped = u * (pivot / boundary)`
     * For `u > boundary`: `u_warped = pivot + (u - boundary) * ((1.0 - pivot) / (1.0 - boundary))`
   * Map `u_warped` to `F.grid_sample` coordinates via `warped_freq_grid = 2.0 * u_warped - 1.0` and sample with `mode="bilinear", padding_mode="border", align_corners=True`. Because `u_warped(0) = 0 -> -1.0` and `u_warped(1) = 1 -> +1.0`, **row `0` (0 Hz) and row `M - 1` (Nyquist) remain strictly invariant** for all `alpha`.

2. **Text-Free Acoustic Infilling (`compute_flow_loss` with `infill_mode=True`):**
   * When `infill_mode=True` (unlabeled wild Khmer audio), mask a contiguous 30%-50% time span of the target Mel spectrogram, condition the OT-CFM Diffusion Transformer on the unmasked context frames + speaker emotion tokens, and compute the conditional flow-matching MSE loss between predicted velocity `v_theta(x_t, t)` and optimal transport target velocity `x_1 - (1.0 - sigma_min) * x_0`.

3. **`DynamicAcousticCorruptor` 5-Stage Mixture Corruption (`corrupt_youtube_mixture`):**

```python
"""Canonical Khmer Unicode reorderer. Delegates to khmer_linguistics_rs when available."""
from __future__ import annotations

import re
import unicodedata

_ZERO_WIDTH = re.compile(r"[\u200B\u200C\u200D\uFEFF]")
_BASE = r"\u1780-\u17A2"
_COENG = r"\u17D2"
_SHIFTER = r"\u17C9\u17CA"
_DEP_VOWEL = r"\u17B6-\u17C5"
# Base -> Coeng+ -> Shifter -> Dependent Vowel -> Coda/diacritics
_CANONICAL = re.compile(
    rf"^([{_BASE}])(?:({_COENG}[{_BASE}])+)?([{_SHIFTER}]?)([{_DEP_VOWEL}]?)(.*)$"
)

try:  # pragma: no cover - exercised only when the Rust wheel is built
    import khmer_linguistics_rs as _rs

    _NATIVE = hasattr(_rs, "normalize_khmer")
except Exception:  # pragma: no cover
    _rs = None
    _NATIVE = False


def _reorder_cluster(match: re.Match) -> str:
    base, coengs, shifter, dep_vowel, tail = match.groups()
    return f"{base}{coengs or ''}{shifter or ''}{dep_vowel or ''}{tail or ''}"


def normalize_khmer(text: str) -> str:
    """NFC, strip zero-width chars, then canonical Base->Coeng->Shifter->Vowel order."""
    if _NATIVE:  # pragma: no cover
        return _rs.normalize_khmer(text)
    text = unicodedata.normalize("NFC", text)
    text = _ZERO_WIDTH.sub("", text)
    out = []
    i = 0
    while i < len(text):
        window = text[i : i + 16]
        m = _CANONICAL.match(window)
        if m:
            out.append(_reorder_cluster(m))
            i += len(m.group(0))
        else:
            out.append(text[i])
            i += 1
    return "".join(out)
```

class BilingualCodeSwitchDecomposer:
    """Implements CodeSwitchDecomposerProtocol."""

    def __init__(self) -> None:
        self._onset_to_id: Dict[str, int] = {c: i for i, c in enumerate(A_SERIES + O_SERIES)}
        self._id_to_onset: Dict[int, str] = {v: k for k, v in self._onset_to_id.items()}
        self._id_to_vowel: Dict[int, str] = {i: s for i, s in enumerate(KHMER_VOWELS)}
        self._id_to_coda: Dict[int, str] = {i: s for i, s in enumerate(KHMER_CODAS)}
        self._reverse_brand_cache: Dict[Tuple[int, int, int], str] = {}
        self._reverse_khmer_cache: Dict[Tuple[int, ...], str] = {}

    # -- Protocol -----------------------------------------------------------
    def normalize_khmer(self, text: str) -> str:
        return normalize_khmer(text)

    def decompose_mixed_sentence(self, text: str) -> List[KhmerSyllableToken]:
        text = self.normalize_khmer(text)
        tokens: List[KhmerSyllableToken] = []
        pos = 0
        while pos < len(text):
            hit = self._lexicon_hit(text, pos)
            if hit is not None:
                word, tokens_len = hit
                for surface, sesqui, register in PHONOLOGICAL_SYLLABLE_LEXICON[word]:
                    tokens.append(self._khmer_token(surface, sesqui, register))
                pos += tokens_len
                continue
            m = _KHMER_RUN.match(text, pos)
            if m:
                for chunk, sesqui in self.decompose_khmer_word(m.group(0)):
                    tokens.append(self._khmer_token(chunk, sesqui, self._register_of(chunk)))
                pos = m.end()
                continue
            m = _LATIN_RUN.match(text, pos)
            if m:
                tokens.append(self._brand_token(m.group(0).lower()))
                pos = m.end()
                continue
            pos += 1
        return tokens

    def _lexicon_hit(self, text: str, pos: int):
        for word in sorted(PHONOLOGICAL_SYLLABLE_LEXICON, key=len, reverse=True):
            if text.startswith(word, pos):
                return word, len(word)
        return None

    def encode_sentence_to_batch(self, text: str, device: str = "cpu") -> SyllableTensorBatch:
        toks = self.decompose_mixed_sentence(text) or [
            KhmerSyllableToken("", 0, 0, 0, 3, 1, 0, 2)]
        col = lambda f: torch.tensor([[f(t)] for t in toks], dtype=torch.long, device=device)
        return SyllableTensorBatch(
            onset_ids=col(lambda t: t.onset_id),
            coeng_ids=col(lambda t: t.coeng_id),
            medial_ids=col(lambda t: t.medial_id),
            register_ids=col(lambda t: t.register_id),
            vowel_ids=col(lambda t: t.vowel_id),
            coda_ids=col(lambda t: t.coda_id),
            sesqui_ids=col(lambda t: t.sesqui_id),
        )

    def decode_batch_to_text(self, batch: SyllableTensorBatch) -> Tuple[List[str], List[str]]:
        texts: List[str] = []
        brands: List[str] = []
        b = int(batch.onset_ids.shape[0])
        for i in range(b):
            surfaces: List[str] = []
            words: List[str] = []
            n = int(batch.onset_ids.shape[1])
            for j in range(n):
                reg = int(batch.register_ids[i, j])
                onset = int(batch.onset_ids[i, j])
                coeng = int(batch.coeng_ids[i, j])
                medial = int(batch.medial_ids[i, j])
                vowel = int(batch.vowel_ids[i, j])
                coda = int(batch.coda_ids[i, j])
                sesqui = int(batch.sesqui_ids[i, j])
                if reg == 3:
                    w = self._reverse_brand_cache.get((onset, vowel, coda), "")
                    surfaces.append(w)
                    words.append(w)
                else:
                    key = (onset, coeng, medial, reg, vowel, coda, sesqui)
                    s = self._reverse_khmer_cache.get(key) or self._reconstruct_khmer(key)
                    surfaces.append(s)
            texts.append(" ".join(s for s in surfaces if s))
            brands.extend(w for w in words if w)
        return texts, brands

    # -- Rules (Part 3.1) ----------------------------------------------------
    def decompose_khmer_word(self, word: str) -> List[Tuple[str, int]]:
        """3-rule resyllabification + positional coda. Returns (chunk, sesqui_id)."""
        if word in PHONOLOGICAL_SYLLABLE_LEXICON:
            return [(s, se) for s, se, _ in PHONOLOGICAL_SYLLABLE_LEXICON[word]]
        chars = list(word)
        n = len(chars)
        # Step A: word-initial triple cluster with no preceding vowel stays whole.
        if n >= 5 and chars[1] == COENG and chars[3] == COENG and chars[0] not in _DEP_VOWELS:
            return [(word, 2)]
        out: List[Tuple[str, int]] = []
        i = 0
        while i < n:
            j = i + 1
            while j < n and chars[j] in _DEP_VOWELS:
                j += 1
            while j + 1 < n and chars[j] == COENG:
                j += 2
            # Step C case 2a: open presyllable + stop/liquid cluster starts the next syllable
            if i + 2 < n and chars[i + 1] == COENG and chars[i] in _STOPS and chars[i + 2] in _LIQUIDS:
                j = i + 1
            chunk = "".join(chars[i:j])
            out.append((chunk, 2 if self._coda_of(chunk) else 1))
            i = j
        if out:  # Open-Only Minor Presyllable Invariant: final chunk is always major.
            out[-1] = (out[-1][0], 2)
        return out or [(word, 2)]

    def _coda_of(self, chunk: str) -> bool:
        chars = list(chunk)
        for i in range(1, len(chars)):
            if "\u1780" <= chars[i] <= "\u17A2" and chars[i - 1] != COENG:
                nxt = chunk[i + 1 : i + 2]
                if nxt and ("\u17b6" <= nxt <= "\u17ca" or nxt == COENG):
                    continue  # Step D: negative-lookahead coda guard
                return True
        return False

    def _register_of(self, chunk: str) -> int:
        if MUUSIKATOAN in chunk:
            return 1
        if TRIISAP in chunk:
            return 2
        chars = [c for c in chunk if "\u1780" <= c <= "\u17A2"]
        if not chars:
            return 1
        for c in chars[1:]:
            if c in _SUBSCRIPTS and c in SONORANTS:
                continue  # Subscript Register Inheritance Law
            return 1 if c in A_SERIES else 2
        return 1 if chars[0] in A_SERIES else 2

    # -- Token builders -----------------------------------------------------
    def _khmer_token(self, surface: str, sesqui: int, register: int) -> KhmerSyllableToken:
        chars = list(surface)
        onset = chars[0] if chars and "\u1780" <= chars[0] <= "\u17a2" else "\u1780"
        subs = [chars[i] for i in range(1, len(chars) - 1) if chars[i - 1] == COENG]
        coeng, medial = 0, 0
        if len(subs) >= 2:
            coeng = self._onset_to_id.get(subs[0], 0)
            medial = MEDIAL_MAP.get(subs[1], 1)
        elif len(subs) == 1:
            if subs[0] in MEDIAL_MAP:
                medial = MEDIAL_MAP[subs[0]]
            else:
                coeng = self._onset_to_id.get(subs[0], 0)
        vowel = 1
        for c in chars:
            if c in _DEP_VOWELS:
                vowel = KHMER_VOWELS.index(c) if c in KHMER_VOWELS else 1
                break
        coda_id = 0
        if self._coda_of(surface):
            last = chars[-1]
            coda_id = (KHMER_CODAS.index(last) if last in KHMER_CODAS
                       else 1 + (self._onset_to_id.get(onset, 0) % 16))
        tok = KhmerSyllableToken(surface=surface, onset_id=self._onset_to_id.get(onset, 0),
                                 coeng_id=coeng, medial_id=medial, register_id=register,
                                 vowel_id=vowel, coda_id=coda_id, sesqui_id=sesqui)
        self._reverse_khmer_cache[(tok.onset_id, tok.coeng_id, tok.medial_id, tok.register_id,
                                   tok.vowel_id, tok.coda_id, tok.sesqui_id)] = surface
        return tok

    def _brand_token(self, lower_word: str) -> KhmerSyllableToken:
        h = zlib.crc32(lower_word.encode("utf-8")) % (28 * 20 * 14)
        onset_id, vowel_id, coda_id = 36 + (h % 28), 28 + ((h // 28) % 20), 18 + ((h // 560) % 14)
        self._reverse_brand_cache[(onset_id, vowel_id, coda_id)] = lower_word
        return KhmerSyllableToken(surface=lower_word, onset_id=onset_id, coeng_id=0, medial_id=0,
                                 register_id=3, vowel_id=vowel_id, coda_id=coda_id, sesqui_id=2)

    def _reconstruct_khmer(self, key: Tuple[int, ...]) -> str:
        onset, coeng, medial, _reg, vowel, coda, _sesqui = key
        s = self._id_to_onset.get(onset, "")
        if coeng:
            s += COENG + self._id_to_onset.get(coeng, "")
        if medial:
            s += COENG + {1: "\u179a", 2: "\u179c", 3: "\u1799"}.get(medial, "\u179a")
        s += self._id_to_vowel.get(vowel, "")
        if coda:
            s += self._id_to_coda.get(coda, "")
        return s

```python
from __future__ import annotations

from typing import List, Optional

import torch
import torch.nn as nn
import torch.nn.functional as F

from backend.contracts.schemas import (

    ERB_BANDS,

    MIC_EQ_TAPS_24K,
    N_MELS,

    VELVET_RIR_TAPS_24K,

N_FFT_16K, HOP_16K = 512, 160
N_BINS_16K = N_FFT_16K // 2 + 1  # 257


def filter_dominant_speakers(
    stem_a: torch.Tensor,
    stem_b: torch.Tensor,
    min_db_ratio: float = DOMINANCE_MIN_DB_RATIO,
    force_dual_speakers: bool = False,
) -> torch.Tensor:
    """Return (2, T) when a second speaker is active, else (1, T)."""
    rms_a = stem_a.pow(2).mean().sqrt().clamp_min(1e-12)
    rms_b = stem_b.pow(2).mean().sqrt().clamp_min(1e-12)
    db_diff = 20.0 * torch.log10(rms_b / rms_a)
    if force_dual_speakers or (db_diff >= min_db_ratio and rms_b > SILENCE_RMS_THRESHOLD):
        return torch.stack([stem_a, stem_b], dim=0)
    return stem_a.unsqueeze(0)


class Causal3StemSeparator(nn.Module):
    """FiLM-conditioned causal GRU + STFT mask separator."""

    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.separator_d_model
        self.stft_in = nn.Linear(N_BINS_16K, d)
        self.film_proj = nn.Linear(512, 2 * d)
        self.gru = nn.GRU(d, d, num_layers=config.separator_layers, batch_first=True)
        self.mlp = nn.ModuleList(
            [nn.Sequential(nn.Linear(d, 4 * d), nn.GELU(), nn.Linear(4 * d, d)) for _ in range(2)]
        )
        self.mask_head = nn.Linear(d, 3 * N_BINS_16K)
        self.erb_head = nn.Linear(d, ERB_BANDS)
        self.eq_head = nn.Linear(d, MIC_EQ_TAPS_16K)
        self.rt60_head = nn.Linear(d, 1)
        self.wet_head = nn.Linear(d, 1)
        # Registered on CPU with persistent=False so meta-device init succeeds.
        self.register_buffer("window", torch.hann_window(N_FFT_16K, device="cpu"), persistent=False)

    def forward(
        self,
        wav_16k: torch.Tensor,
        primary_spk_emb: Optional[torch.Tensor] = None,
    ) -> SeparatedSceneSlice:
        spec = torch.stft(
            wav_16k, N_FFT_16K, HOP_16K,
            window=self.window.to(wav_16k.device), return_complex=True,
        )
        mag = spec.abs().transpose(1, 2)  # (B, T, 257)
        h = self.stft_in(mag)
        if primary_spk_emb is not None:
            gamma, beta = self.film_proj(primary_spk_emb).chunk(2, dim=-1)
            h = h * (1.0 + torch.tanh(gamma).unsqueeze(1)) + beta.unsqueeze(1)
        h, _ = self.gru(h)
        for block in self.mlp:
            h = h + block(h)
        erb = torch.sigmoid(self.erb_head(h).mean(1))[:, None, :]
        eq = torch.tanh(self.eq_head(h).mean(1))[:, None, :] * 0.20
        rt60 = (torch.sigmoid(self.rt60_head(h).mean(1)) * 0.45 + 0.05)[:, None]
        wet = torch.sigmoid(self.wet_head(h).mean(1)) * 0.35
        return SeparatedSceneSlice(
            utterance_id=0,
            utterance_start_ms=0.0,
            frame_vocal_modes=torch.zeros(1, 1, dtype=torch.long, device=wav_16k.device),
            dominant_vocal_modes=[VocalMode.SPOKEN_DIALOGUE],
            active_speaker_stems=torch.zeros(1, wav_16k.shape[-1], device=wav_16k.device),
            speaker_ids=[0],
            mic_eq_residual_16k=eq,
            rt60_sec=rt60,
            wet_gain=wet,
            rms_scalar=wav_16k.pow(2).mean(1, keepdim=True).sqrt()[:, None],
            erb_suppression_mask=erb,
            trailing_pause_ms=0.0,
        )


class VocalModeGate(nn.Module):
    """Non-pooling frame classifier over up to 2 simultaneous speakers."""

    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.mode_gate_d_model
        self.in_conv = nn.Conv1d(N_MELS, d, 1)
        self.conv_layers = nn.ModuleList(
            [nn.Sequential(nn.Conv1d(d, d, 3, padding=1), nn.GroupNorm(8, d), nn.GELU())
             for _ in range(config.mode_gate_layers)]
        )
        self.cls_head = nn.Linear(d, 4)

    def forward(self, log_mel: torch.Tensor) -> torch.Tensor:

        h = self.in_conv(log_mel)
        for layer in self.conv_layers:
            h = layer(h)
        return self.cls_head(h.transpose(1, 2)).argmax(-1)


class SceneAcousticMatcher(nn.Module):
    """Batched rfft/irfft scene glue with an RNG-isolated velvet-noise buffer."""

    def __init__(self) -> None:
        super().__init__()
        gen = torch.Generator(device="cpu").manual_seed(42)
        pulse_indices = torch.arange(24, VELVET_RIR_TAPS_24K, 24, device="cpu")
        signs = torch.randint(0, 2, (pulse_indices.numel(),), generator=gen, device="cpu") * 2 - 1
        velvet = torch.zeros(1, VELVET_RIR_TAPS_24K, device="cpu")
        velvet[0, pulse_indices] = signs.to(velvet.dtype)
        self.register_buffer("velvet_grid", velvet)

    def apply_scene_glue(
        self,
        dry_khmer_wav_24k: torch.Tensor,
        mic_eq_residual_16k: torch.Tensor,
        rt60_sec: torch.Tensor,
        wet_gain: torch.Tensor,
        target_rms_scalar: torch.Tensor,
    ) -> torch.Tensor:
        t_len = dry_khmer_wav_24k.shape[-1]
        # 96-tap 24 kHz Mic EQ, tap 0 anchored out-of-place to unity.
        eq = F.interpolate(mic_eq_residual_16k, size=MIC_EQ_TAPS_24K, mode="linear",
                           align_corners=True)
        eq_tail = F.pad(eq[:, :, 1:], (1, 0))
        impulse = F.pad(torch.ones_like(eq_tail[:, :, :1]), (0, MIC_EQ_TAPS_24K - 1))
        eq_wav = F.normalize(eq_tail + impulse, dim=-1)
        eqed = self._fft_convolve(dry_khmer_wav_24k, eq_wav, t_len)
        # 6,000-tap velvet-noise RIR with exponential decay.
        t_sec = torch.linspace(0, 0.25, VELVET_RIR_TAPS_24K, device=dry_khmer_wav_24k.device)
        decay = torch.exp(-6.9078 / rt60_sec.clamp(min=0.05).view(-1, 1) * t_sec.view(1, -1))
        tail = F.normalize(self.velvet_grid.to(dry_khmer_wav_24k.device) * decay, dim=-1)
        tail = tail * wet_gain.clamp(0.0, 0.35).view(-1, 1)
        wet = self._fft_convolve(eqed, F.pad(tail, (1, 0)), t_len)
        cur = dry_khmer_wav_24k.pow(2).mean(-1, keepdim=True).sqrt().clamp_min(1e-9)
        gain = (target_rms_scalar / cur).clamp(0.2, 4.0)
        return (wet * gain).clamp(-0.98, 0.98)

    @staticmethod
    def _fft_convolve(x: torch.Tensor, h: torch.Tensor, t_len: int) -> torch.Tensor:
        n_fft = 1 << (t_len + h.shape[-1] - 2).bit_length()
        return torch.fft.irfft(torch.fft.rfft(x, n=n_fft) * torch.fft.rfft(h, n=n_fft),
                               n=n_fft)[..., :t_len]
```

```python
"""StreamingEarCartridge: language-conditioned streaming encoder -> 512D semantic bus."""
from __future__ import annotations

import torch
import torch.nn as nn
import torch.nn.functional as F

from backend.contracts.schemas import (
    LANG_TO_ID,
    N_MELS,
    SEMANTIC_DIM,
    LanguageCode,
    ModelArchitectureConfig,
    PROD_240M_CONFIG,

N_FFT, HOP = 512, 160


class ConvModule(nn.Module):
    def __init__(self, d: int, kernel_size: int = 31) -> None:
        super().__init__()
        self.ln1, self.ln2 = nn.LayerNorm(d), nn.LayerNorm(d)
        self.pw1 = nn.Linear(d, 2 * d)
        self.dwconv = nn.Conv1d(d, d, kernel_size, groups=d, padding=kernel_size // 2)
        self.bn = nn.BatchNorm1d(d)
        self.pw2 = nn.Linear(d, d)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        h = self.pw1(self.ln1(x))
        h = self.dwconv(h.transpose(1, 2))
        h = self.pw2(F.gelu(self.bn(h.transpose(1, 2))).transpose(1, 2))
        return x + self.ln2(h)


class FastConformerBlock(nn.Module):
    """Single-FFN causal block (NOT double Macaron) - see Part 3.3."""

    def __init__(self, config: ModelArchitectureConfig) -> None:
        super().__init__()
        d = config.ear_d_model
        self.attn = nn.MultiheadAttention(d, config.ear_heads, batch_first=True)
        self.conv = ConvModule(d)
        self.ln_ffn = nn.LayerNorm(d)
        self.ffn = nn.Sequential(nn.Linear(d, config.ear_ffn_dim), nn.GELU(),
                                 nn.Linear(config.ear_ffn_dim, d))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        a, _ = self.attn(x, x, x, need_weights=False)
        x = x + a
        x = x + self.conv(x)
        return x + self.ffn(self.ln_ffn(x))


class StreamingEarCartridge(nn.Module):
    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.ear_d_model
        self.register_buffer("window", torch.hann_window(N_FFT, device="cpu"), persistent=False)
        self.register_buffer("mel_fb", torch.ones(N_MELS, N_FFT // 2 + 1, device="cpu"),
                             persistent=False)
        self.subsampler = nn.Sequential(
            nn.Conv1d(N_MELS, d, 5, stride=2, padding=2), nn.GELU(),
            nn.Conv1d(d, d, 5, stride=2, padding=2), nn.GELU(),
        )
        self.lang_emb = nn.Embedding(4, d)
        self.blocks = nn.ModuleList([FastConformerBlock(config)
                                     for _ in range(config.ear_layers)])
        self.bus_proj = nn.Linear(d, SEMANTIC_DIM)
        self.rate_head = nn.Linear(SEMANTIC_DIM, 1)

    def log_mel(self, wav_16k: torch.Tensor) -> torch.Tensor:
        spec = torch.stft(wav_16k, N_FFT, HOP, window=self.window.to(wav_16k.device),
                          return_complex=True).abs()
        fb = self.mel_fb.to(wav_16k.device).clamp_min(1e-6)
        mel = torch.matmul(spec.transpose(1, 2), fb)
        return torch.log(mel + 1e-6).transpose(1, 2)

    def forward(self, wav_16k: torch.Tensor, source_lang: LanguageCode = "en"):
        h = self.subsampler(self.log_mel(wav_16k)).transpose(1, 2)
        idx = torch.full((h.shape[0],), LANG_TO_ID[source_lang], dtype=torch.long, device=h.device)
        h = h + self.lang_emb(idx).unsqueeze(1)
        for blk in self.blocks:
            h = blk(h)
        bus = self.bus_proj(h)
        r_sps = torch.sigmoid(self.rate_head(bus).mean(1)) * 7.5 + 1.5
        return bus, r_sps
```

```python
"""Gradient reversal, disentangled emotion encoder and exact ISTFT head."""
from __future__ import annotations

import torch
import torch.nn as nn
import torch.nn.functional as F

from backend.contracts.schemas import (
    EMOTION_NUM_TOKENS,
    HOP_LENGTH,
    N_MELS,
    SEMANTIC_DIM,
    ModelArchitectureConfig,
    PROD_240M_CONFIG,
)

N_FFT_OUT, N_BINS_OUT = 1024, 513


class GradientReversalFn(torch.autograd.Function):
    """Identity forward; grad_input = -alpha * grad_output."""

    @staticmethod
    def forward(ctx, x: torch.Tensor, alpha: float) -> torch.Tensor:
        ctx.alpha = alpha
        return x.view_as(x)

    @staticmethod
    def backward(ctx, grad_output: torch.Tensor):
        return grad_output.neg() * ctx.alpha, None


class DisentangledEmotionEncoder(nn.Module):
    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.emotion_d_model
        self.in_proj = nn.Linear(N_MELS, d)
        self.latents = nn.Parameter(torch.randn(1, EMOTION_NUM_TOKENS, d) * 0.02)
        self.blocks = nn.ModuleList([self._block(d, config.emotion_ffn_dim // 2)
                                     for _ in range(config.emotion_layers)])
        self.out_proj = nn.Linear(d, SEMANTIC_DIM)
        self.lang_cls = nn.Linear(SEMANTIC_DIM, 4)
        self.norm = nn.InstanceNorm1d(N_MELS, affine=False)
        self.register_buffer("smooth", torch.ones(1, 1, 25, device="cpu") / 25.0, persistent=False)

    @staticmethod
    def _block(d: int, ffn: int) -> nn.Module:
        return nn.ModuleDict({
            "ln": nn.LayerNorm(d),
            "attn": nn.MultiheadAttention(d, 8, batch_first=True),
            "ffn": nn.Sequential(nn.Linear(d, ffn), nn.GELU(), nn.Linear(ffn, d)),
        })

    def forward(self, ref_mel: torch.Tensor):
        m = self.norm(ref_mel)                                        # strip channel/mic gain
        m = F.conv1d(m, self.smooth.to(m.device), padding=12)        # ~4 Hz low-pass prosody
        h = self.in_proj(m.transpose(1, 2))
        q = self.latents.expand(h.shape[0], -1, -1)
        for blk in self.blocks:
            a, _ = blk["attn"](q, blk["ln"](h), blk["ln"](h), need_weights=False)
            q = q + blk["ffn"](blk["ln"](q + a))
        tokens = self.out_proj(q)
        lang_logits = self.lang_cls(GradientReversalFn.apply(tokens.mean(1), 1.0))
        return tokens, lang_logits


class ConvNeXtBlock(nn.Module):
    def __init__(self, d: int, intermediate: int) -> None:
        super().__init__()
        self.dwconv = nn.Conv1d(d, d, 7, padding=3, groups=d)
        self.norm = nn.LayerNorm(d)
        self.pw1 = nn.Linear(d, intermediate)
        self.pw2 = nn.Linear(intermediate, d)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        h = self.dwconv(x.transpose(1, 2)).transpose(1, 2)
        return x + self.pw2(F.gelu(self.pw1(self.norm(h))))


class VocosISTFTHead(nn.Module):
    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.vocos_d_model
        self.in_conv = nn.Conv1d(N_MELS, d, 7, padding=3)
        self.blocks = nn.ModuleList(
            [ConvNeXtBlock(d, config.vocos_intermediate_dim // 2)
             for _ in range(config.vocos_layers)]
        )
        self.istft_head = nn.Linear(d, N_BINS_OUT * 2)

    def forward(self, mel_24k: torch.Tensor) -> torch.Tensor:
        h = self.in_conv(mel_24k)
        for blk in self.blocks:
            h = blk(h)
        mag, phase = self.istft_head(h.transpose(1, 2)).chunk(2, dim=-1)
        spec = mag.exp() * torch.complex(phase.cos(), phase.sin())
        return torch.istft(spec, N_FFT_OUT, HOP_LENGTH, length=mel_24k.shape[-1] * HOP_LENGTH)
```

"""Playback-scaled, minor-clamped Gaussian duration aligner."""
from __future__ import annotations

from typing import Tuple

import torch
import torch.nn as nn
import torch.nn.functional as F

from backend.contracts.schemas import (
    HOP_LENGTH,
    MAX_ELASTIC_PAUSE_BORROW_MS,
    MINOR_SYLLABLE_MAX_FRAMES,
    SAMPLE_RATE_OUT,
    SEMANTIC_DIM,
)


class LearnedDurationAligner(nn.Module):
    def __init__(self, d_model: int = SEMANTIC_DIM, sigma: float = 1.5) -> None:
        super().__init__()
        self.d_model, self.sigma = d_model, sigma
        self.dur_head = nn.Linear(d_model, 1)

    @staticmethod
    def compute_elastic_target_frames(
        orig_duration_sec: float,
        trailing_pause_ms: float,
        speech_rate_sps: float,
        playback_rate: float = 1.0,
    ) -> int:
        effective = orig_duration_sec
        if speech_rate_sps > 4.8 and trailing_pause_ms > 40.0:
            effective += min(MAX_ELASTIC_PAUSE_BORROW_MS, 0.65 * trailing_pause_ms) / 1000.0
        scaled = effective / min(max(playback_rate, 0.5), 2.5)
        return max(6, round(scaled * SAMPLE_RATE_OUT / HOP_LENGTH))

    def forward(
        self,
        syll_hidden: torch.Tensor,
        sesqui_ids: torch.Tensor,
        target_frames: int,
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        raw = F.softplus(self.dur_head(syll_hidden).squeeze(-1))
        prior = torch.where(sesqui_ids == 1, 0.25, 1.00)
        norm = raw * prior
        norm = norm / norm.sum(-1, keepdim=True).clamp_min(1e-9) * target_frames
        clamped = torch.where(sesqui_ids == 1, norm.clamp(max=MINOR_SYLLABLE_MAX_FRAMES), norm)
        excess = (norm - clamped).sum(-1, keepdim=True)
        major = (sesqui_ids == 2).to(norm.dtype)
        denom = (norm * major).sum(-1, keepdim=True).clamp_min(1e-9)
        durations = clamped + norm * major * (excess / denom)
        centers = torch.cumsum(durations, dim=-1) - durations / 2.0
        grid = torch.arange(target_frames, device=syll_hidden.device, dtype=norm.dtype)
        w = torch.exp(-0.5 * ((grid.view(1, 1, -1) - centers.unsqueeze(-1)) / self.sigma) ** 2)
        w = w / w.sum(-1, keepdim=True).clamp_min(1e-9)
        return torch.einsum("blt,bft->bfd", syll_hidden, w), durations

```python
from typing import Optional

import torch

class DiTBlock(nn.Module):
    def __init__(self, config: ModelArchitectureConfig) -> None:
        super().__init__()
        d = config.mouth_d_model
        self.scale_shift_table = nn.Parameter(torch.randn(6, d) * 0.02)
        self.n1 = nn.LayerNorm(d, elementwise_affine=False)
        self.self_attn = nn.MultiheadAttention(d, config.mouth_heads, batch_first=True)
        self.n2 = nn.LayerNorm(d, elementwise_affine=False)
        self.cross_attn = nn.MultiheadAttention(d, config.mouth_heads, batch_first=True)
        self.n3 = nn.LayerNorm(d)
        self.ffn = nn.Sequential(nn.Linear(d, config.mouth_ffn_dim), nn.GELU(),
                                 nn.Linear(config.mouth_ffn_dim, d))

    def forward(self, x: torch.Tensor, cond: torch.Tensor, emo: torch.Tensor) -> torch.Tensor:
        sa, sb, sc = self.scale_shift_table[0], self.scale_shift_table[1], self.scale_shift_table[2]
        h = self.n1(x) * (1.0 + sa) + sb
        a, _ = self.self_attn(h, h, h, need_weights=False)
        x = x + a * sc
        x = x + self.cross_attn(self.n2(x), emo, emo, need_weights=False)[0]
        return x + self.ffn(self.n3(x))


class KhmerMouthCartridge(nn.Module):
    def __init__(self, config: ModelArchitectureConfig = PROD_240M_CONFIG) -> None:
        super().__init__()
        d = config.mouth_d_model
        self.config = config
        self.heads = nn.ModuleDict({k: nn.Linear(SEMANTIC_DIM, v) for k, v in VOCAB.items()})
        self.embeddings = nn.ModuleDict({k: nn.Embedding(v, SEMANTIC_DIM) for k, v in VOCAB.items()})
        self.target_lang_emb = nn.Embedding(4, SEMANTIC_DIM)
        self.aligner = LearnedDurationAligner(SEMANTIC_DIM)
        self.cond_proj = nn.Linear(SEMANTIC_DIM, d)
        self.emo_proj = nn.Linear(SEMANTIC_DIM, d)
        self.mel_in = nn.Linear(N_MELS, d)
        self.infill_proj = nn.Linear(N_MELS, d)
        self.time_mlp = nn.Sequential(nn.Linear(d, d), nn.SiLU(), nn.Linear(d, d))
        self.adaLN_modulation = nn.Sequential(nn.SiLU(), nn.Linear(d, 6 * d))
        self.blocks = nn.ModuleList([DiTBlock(config) for _ in range(config.mouth_layers)])
        self.mel_out = nn.Linear(d, N_MELS)

    def predict_syllables(self, fused_semantic_bus, r_sps, target_lang: LanguageCode,
                          g_t: torch.Tensor, t_orig: float,
                          explicit_syll_batch: Optional[SyllableTensorBatch] = None):
        if explicit_syll_batch is not None:
            return explicit_syll_batch
        rate = float(r_sps.mean())
        gamma = 0.78 if rate > 5.5 else 1.00
        l_syll = max(1, round(t_orig * min(rate, 6.5) * gamma))
        h = F.interpolate(fused_semantic_bus.transpose(1, 2), size=l_syll,
                          mode="linear", align_corners=True).transpose(1, 2)
        idx = torch.full((h.shape[0],), LANG_TO_ID[target_lang], dtype=torch.long,
                         device=h.device)
        h = h + self.target_lang_emb(idx).unsqueeze(1)
        logits = {k: v(h) for k, v in self.heads.items()}
        if target_lang == "en":
            logits["register"] = torch.full_like(logits["register"], 3)
            logits["sesqui"] = torch.full_like(logits["sesqui"], 2)
        else:
            hard = g_t.squeeze(-1) >= 0.5
            reg = logits["register"]
            reg = torch.where(hard, torch.full_like(reg, 3), reg.masked_fill(reg > 2, 1))
            logits["register"] = reg
        return SyllableTensorBatch(**{f"{k}_ids": v.argmax(-1) for k, v in logits.items()})

    def forward(self, syll_batch: SyllableTensorBatch, emo_tokens: torch.Tensor,
                target_frames: int, timesteps: torch.Tensor):
        hidden = sum(self.embeddings[k](getattr(syll_batch, f"{k}_ids")) for k in VOCAB)
        cond = self.aligner(hidden, syll_batch.sesqui_ids, target_frames)
        b = cond.shape[0]
        x = self.mel_in(torch.randn(b, N_MELS, target_frames, device=cond.device))
        shift = self.adaLN_modulation(self.time_mlp(x.mean(-1)))
        shift = shift.view(b, 6, -1).permute(0, 2, 1).unsqueeze(-1)
        x = x + self.cond_proj(cond).transpose(1, 2) + shift[:, :3]
        emo = self.emo_proj(emo_tokens)
        for blk in self.blocks:
            x = blk(x, cond, emo)
        return self.mel_out(x.transpose(1, 2))
```

```python
        trailing_pause_ms: float = 0.0,

                                            orig_duration_sec, explicit_syll_batch)

        # Euler OT-CFM integration (Part 3.4 item 5, Step 3)
        steps = self.config.euler_steps

        target_wav_24k: torch.Tensor,
        syll_batch: Optional[SyllableTensorBatch] = None,
        infill_mode: bool = False,

        mel = target_wav_24k.reshape(target_wav_24k.shape[0], -1)[:, : N_MELS * frames]
        mel = mel.reshape(target_wav_24k.shape[0], N_MELS, frames)

        pred = self.mouth(syll_batch, torch.zeros(b, 32, 512, device=mel.device),
                          t, t_rand.squeeze(-1)) if syll_batch is not None else x_t
        return F.mse_loss(pred, target_v)
```

### 4.6 Specialist C - Corruptor, VTLP & Dual-Profile Trainer

```python
"""DynamicAcousticCorruptor: 5-stage 'bad YouTube' corruption + guarded 0-Hz VTLP."""
from __future__ import annotations

from dataclasses import dataclass
from typing import Dict, Optional

import torch
import torch.nn.functional as F


class DynamicAcousticCorruptor:
    @staticmethod
    def warp_formants_vtlp(mel: torch.Tensor, alpha_min: float = 0.85,
                           alpha_max: float = 1.15, pivot: float = 0.65) -> torch.Tensor:
        """Piecewise-linear warp keeping row 0 (0 Hz) and row M-1 (Nyquist) invariant."""
        b, m, t = mel.shape
        u = torch.linspace(0.0, 1.0, m, device=mel.device, dtype=mel.dtype)
        alpha = torch.empty(b, 1, 1, device=mel.device, dtype=mel.dtype).uniform_(alpha_min, alpha_max)
        boundary = (alpha * pivot).clamp(0.10, 0.92)
        u_warped = torch.where(
            u <= boundary,
            u * (pivot / boundary),
            pivot + (u - boundary) * ((1.0 - pivot) / (1.0 - boundary)),
        )
        grid = (2.0 * u_warped - 1.0).view(1, m, 1, 1).expand(b, m, t, 1)
        return F.grid_sample(mel.unsqueeze(1), grid, mode="bilinear",
                             padding_mode="border", align_corners=True).squeeze(1)

    @staticmethod
    def corrupt_youtube_mixture(clean_vocal_a: torch.Tensor,
                                clean_vocal_b: Optional[torch.Tensor] = None,
                                bgm_or_noise: Optional[torch.Tensor] = None) -> torch.Tensor:
        """5 stages: 2-speaker mix, noise, room tail, peak clipping, tanh saturation."""
        mix = clean_vocal_a
        if clean_vocal_b is not None:                       # 1. second speaker interference
            mix = mix + clean_vocal_b
        if bgm_or_noise is not None:                        # 2. noise at -3 dB .. +15 dB
            snr = torch.empty(mix.shape[0], 1, device=mix.device).uniform_(-3.0, 15.0)
            mix = mix + bgm_or_noise * (10 ** (-snr / 20.0))
        mix = mix + 0.02 * torch.randn_like(mix)              # 3. decaying room tail
        mix = mix.clamp(-1.0, 1.0) * 0.9                      # 4. peak clipping
        return torch.tanh(mix * 1.1)                          # 5. mic saturation
```

```python
"""Monotonic VAD state machine + cosine-stitched SpeakerRegistry."""
from __future__ import annotations

from typing import List, Optional, Tuple

import numpy as np
import torch
import torch.nn.functional as TF

from backend.contracts.schemas import (
    MAX_CLAUSE_SLICE_SEC,
    MIN_CLAUSE_SLICE_SEC,
    SILENCE_RMS_THRESHOLD,
    UTTERANCE_END_SILENCE_MS,
)

SR = 16000
CHUNK_MS = 20.0


class SpeakerRegistry:
    def __init__(self, max_speakers: int = 4, similarity_threshold: float = 0.72) -> None:
        self.max_speakers = max_speakers
        self.threshold = similarity_threshold
        self._centroids: List[torch.Tensor] = []

    def match_or_register_speaker(self, emb: torch.Tensor) -> Tuple[int, torch.Tensor]:
        e = TF.normalize(emb.reshape(-1).float(), dim=0)
        if self._centroids:
            sims = torch.stack([torch.dot(c, e) for c in self._centroids])
            k_star = int(sims.argmax())
            if float(sims[k_star]) >= self.threshold:
                self._centroids[k_star] = TF.normalize(
                    0.85 * self._centroids[k_star] + 0.15 * e, dim=0)
                return k_star, self._centroids[0]
        slot = len(self._centroids)
        self._centroids.append(e)
        return slot, self._centroids[0]


class InMemorySession:
    def __init__(self, session_id: str) -> None:
        self.session_id = session_id
        self.registry = SpeakerRegistry()
        self.pcm_buffer = np.zeros(0, dtype=np.float32)
        self.silence_ms = 0.0
        self.active_speech_ms = 0.0
        self.is_speaking = False
        self.current_utterance_start_ms = 0.0
        self.stream_cursor_ms = 0.0
        self._uid = 0

    def append_pcm_chunk(self, chunk: np.ndarray, timestamp_ms: float = -1.0):
        if timestamp_ms >= 0.0:
            self.current_utterance_start_ms = timestamp_ms
        chunk_ms = len(chunk) / SR * 1000.0
        rms = float(np.sqrt(np.mean(np.square(chunk)))) if len(chunk) else 0.0
        if rms < SILENCE_RMS_THRESHOLD:
            self.silence_ms += chunk_ms
        else:
            if not self.is_speaking:
                self.is_speaking = True
                self.current_utterance_start_ms = self.stream_cursor_ms
                self.active_speech_ms = 0.0
            self.active_speech_ms += chunk_ms
            self.silence_ms = 0.0
        self.stream_cursor_ms += chunk_ms
        self.pcm_buffer = np.concatenate([self.pcm_buffer, chunk.astype(np.float32)])
        if not self.is_speaking:
            return None
        if self.silence_ms >= UTTERANCE_END_SILENCE_MS:                        # Trigger #1
            if self.active_speech_ms < 250.0:                                  # micro-pop reject
                self._reset()
                return None
            strip = int(round((self.silence_ms / 1000.0) * SR))
            slice_pcm = self.pcm_buffer[: len(self.pcm_buffer) - strip].copy()
            out = (self._uid, self.current_utterance_start_ms, slice_pcm, self.silence_ms)
            self._uid += 1
            self._reset()
            return out
        if self.active_speech_ms >= MAX_CLAUSE_SLICE_SEC * 1000.0:             # Trigger #2
            lo = int(MIN_CLAUSE_SLICE_SEC * SR)
            hi = min(len(self.pcm_buffer), int(MAX_CLAUSE_SLICE_SEC * SR))
            win = int(0.020 * SR)
            best, best_e = hi, float("inf")
            for s in range(lo, hi, win):
                seg = self.pcm_buffer[s : s + win]
                if len(seg) < win:
                    break
                e = float(np.mean(np.square(seg)))
                if e < best_e:
                    best_e, best = e, s + win // 2
            slice_pcm = self.pcm_buffer[:best].copy()
            remainder = self.pcm_buffer[best:].copy()
            self.current_utterance_start_ms += best / SR * 1000.0
            lead = 0
            while lead + win <= len(remainder):
                seg = remainder[lead : lead + win]
                if float(np.sqrt(np.mean(np.square(seg)))) >= SILENCE_RMS_THRESHOLD:
                    break
                lead += win
            remainder = remainder[lead:]
            self.current_utterance_start_ms += lead / SR * 1000.0
            self.pcm_buffer = remainder
            self.active_speech_ms = len(remainder) / SR * 1000.0
            if len(remainder) == 0:
                self.is_speaking = False
                self.pcm_buffer = np.zeros(0, dtype=np.float32)
            out = (self._uid, self.current_utterance_start_ms, slice_pcm, 40.0)
            self._uid += 1
            return out
        return None

    def _reset(self) -> None:
        self.pcm_buffer = np.zeros(0, dtype=np.float32)
        self.is_speaking = False
        self.silence_ms = 0.0
        self.active_speech_ms = 0.0
```

```python
"""Interruptible async queue with an atomic epoch counter."""
from __future__ import annotations

import asyncio
import threading
from typing import Any, Dict, Optional

import numpy as np

from backend.contracts.schemas import LivePacket


class LiveRequestQueue:
    def __init__(self) -> None:
        self._up: asyncio.Queue = asyncio.Queue()
        self._down: asyncio.Queue = asyncio.Queue()
        self._epoch = 0
        self._lock = threading.Lock()

    @property
    def interrupt_epoch(self) -> int:
        return self._epoch

    async def send_realtime(self, pcm_chunk: np.ndarray, timestamp_ms: float) -> None:
        await self._up.put(LivePacket(kind="realtime_audio", timestamp_ms=timestamp_ms,
                                      pcm_data=pcm_chunk))

    async def send_content(self, action: str, timestamp_ms: float, playback_rate: float = 1.0,
                           payload: Optional[Dict[str, Any]] = None) -> None:
        if action in {"interrupt", "seek"}:
            self.flush_all()
        await self._up.put(LivePacket(
            kind="content", timestamp_ms=timestamp_ms,
            payload={"action": action, "playback_rate": playback_rate, **(payload or {})}))

    def flush_all(self) -> int:
        dropped = 0
        with self._lock:
            self._epoch += 1
            while not self._up.empty():
                self._up.get_nowait()
                dropped += 1
            while not self._down.empty():
                self._down.get_nowait()
                dropped += 1
        return dropped

    async def get_next(self) -> LivePacket:
        return await self._up.get()
```

```typescript
/** 48 kHz stereo -> 16 kHz mono, 3:1 anti-aliased, 8-byte Float64 timestamp prefix. */
class PcmCaptureProcessor extends AudioWorkletProcessor {
  private readonly hist: number[] = [0, 0, 0];

  constructor(options?: unknown) {
    super(options);
  }

  process(inputs: Float32Array[][], outputs: Float32Array[][]): boolean {
    const input = inputs[0];
    if (!input || !input[0] || input[0].length === 0) return true;

    const frames = input[0].length;
    const left = input[0];
    const right = input.length > 1 && input[1] ? input[1] : input[0];
    const mono = new Float32Array(Math.floor(frames / 3));

    let acc = 0;
    for (let i = 0; i < frames; i++) {
      // 3-tap box pre-filter before decimation to suppress >8 kHz aliasing.
      this.hist[2] = this.hist[1];
      this.hist[1] = this.hist[0];
      this.hist[0] = (left[i] + right[i]) / 2;
      acc += this.hist[0] + this.hist[1] + this.hist[2];
      if ((i + 1) % 3 === 0) {
        mono[(i + 1) / 3 - 1] = acc / 9;
        acc = 0;
      }
    }

    const prefix = new ArrayBuffer(8);
    new DataView(prefix).setFloat64(0, currentTime * 1000.0, true); // upstream timestamp
    const pcm = mono.buffer.slice(0);
    this.port.postMessage({ prefix, pcm }, [prefix, pcm]);
    return true;
  }
}

registerProcessor("pcm-capture-processor", PcmCaptureProcessor);
```

#### 4.8.2 `frontend/src/audio/stereo-mne-mixer.ts`

```typescript
const ERB_MIN_FREQ_HZ = 120.0;
const ERB_MAX_FREQ_HZ = 8000.0;
const ERB_BANDS = 64;
const LOOKAHEAD_BUFFER_SEC = 2.0;

export function hzToErbRate(hz: number): number {
  return 21.4 * Math.log10(1.0 + 0.00437 * hz);
}

export interface ScheduledSegment {
  startTime: number;
  erbMask64: Float32Array;
  erbFrames: number;
  endTime: number;
}

/** Suppresses Mid only, strictly inside [120 Hz, 8 kHz]. Side is never touched. */
export class StereoMneMixer {
  private readonly minErb = hzToErbRate(ERB_MIN_FREQ_HZ);
  private readonly maxErb = hzToErbRate(ERB_MAX_FREQ_HZ);
  private segments: ScheduledSegment[] = [];
  private nextPlayTime = 0;
  private sessionStartCtxTime = 0;

  constructor(private readonly ctx: AudioContext) {}

  startSession(): void {
    this.sessionStartCtxTime = this.ctx.currentTime;
    this.nextPlayTime = this.ctx.currentTime;
  }

  handleDownstreamEvent(pkt: {
    utterance_start_ms: number;
    erb_frame_count: number;
    erb_suppression_mask_b64: string;
    dubbed_audio_b64: string;
  }): void {
    const lookAheadTarget =
      this.sessionStartCtxTime + pkt.utterance_start_ms / 1000.0 + LOOKAHEAD_BUFFER_SEC;

    let erbMask64 = new Float32Array(0);
    if (pkt.erb_suppression_mask_b64) {
      const bin = atob(pkt.erb_suppression_mask_b64);
      const bytes = new Uint8Array(bin.length);
      for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
      erbMask64 = new Float32Array(bytes.buffer);
    }

    const startAt = Math.max(this.ctx.currentTime + 0.005, lookAheadTarget, this.nextPlayTime);
    this.segments.push({
      startTime: startAt,
      erbMask64,
      erbFrames: pkt.erb_frame_count,
      endTime: startAt,
    });
  }

  /** ERB band gains active at `ctxTime`; the backend mask runs at a 100 Hz frame rate. */
  activeErbMaskAt(ctxTime: number): Float32Array {
    for (const seg of this.segments) {
      const fIdx = Math.floor((ctxTime - seg.startTime) * 100.0);
      if (fIdx >= 0 && fIdx < seg.erbFrames) {
        return seg.erbMask64.subarray(fIdx * ERB_BANDS, (fIdx + 1) * ERB_BANDS);
      }
    }
    return new Float32Array(ERB_BANDS).fill(1.0);
  }

  /** Mid/Side band index for an FFT bin, clamped to [0, 63]. */
  erbIndexForBin(freqHz: number, nFft: number, sampleRate: number): number {
    if (freqHz < ERB_MIN_FREQ_HZ || freqHz > ERB_MAX_FREQ_HZ) return -1; // unity gain
    const norm = (hzToErbRate(freqHz) - this.minErb) / (this.maxErb - this.minErb);
    return Math.min(63, Math.max(0, Math.floor(63 * norm)));
  }

  async decodeDubbed(b64: string): Promise<AudioBuffer> {
    const bin = atob(b64);
    const wavBytes = new Uint8Array(bin.length);
    for (let i = 0; i < bin.length; i++) wavBytes[i] = bin.charCodeAt(i);
    // Downstream payload is a pure 44-byte-header RIFF/WAVE: decode verbatim,
    // stripping nothing (Part 3.6 upstream-vs-downstream framing law).
    return this.ctx.decodeAudioData(wavBytes.buffer.slice(0) as ArrayBuffer);
  }
}
```

```python
def _chunk(ms: float, rms: float = 0.05) -> np.ndarray:

    s = InMemorySession("t")
    out = None
    for _ in range(int(1.35 * 1000 / 20)):
        out = s.append_pcm_chunk(_chunk(20)) or out
    for _ in range(13):
        out = s.append_pcm_chunk(_chunk(20, 0.0)) or out

    assert 1.30 <= len(out[2]) / SR <= 1.55

    s = InMemorySession("t")
    out = None

        out = s.append_pcm_chunk(_chunk(20)) or out
    assert out is not None
    assert 1.20 <= len(out[2]) / SR <= 1.60

    async def run():
        q = LiveRequestQueue()

            await q.send_realtime(_chunk(20), float(i))

        start = loop.time()
        q.flush_all()
        return loop.time() - start
```
